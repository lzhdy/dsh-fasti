## 1. 背景（一分钟版）

一个虚构生活服务小镇，共 **1920 个事件**，分属 **160 个题材族，每族 12 个事件**。每个事件含 6 句一个人对 AI 说的原话（高危事件 7 句）＋1 句客观摘要。事件按冻结种子哈希切成两个物理隔离的分区：

- **A 区（tuning-a）1404 个事件**：标定卷，允许在预注册上限 **3 轮**内反复用于调参，每轮哈希留痕；
- **B 区（tuning-b）516 个事件**：一次性确认卷，**你只为它出一次题、收卷即用毕封存**，禁止任何人回头据 B 区结果调参。

这 1920 个事件的**机械题**（长度边界、数字变体、编辑距离、诱饵密度、衬词等可由程序确定性生成的桶）由收卷方生成器包办，**不归你写**。你只负责机器写不好的那部分——**自然语言件**：双事件长句、真人换述、自然噪声与弃权句、需要常识判断的澄清/判别句。你交付的条目与机器条目在收卷方汇合，经机械校验、答案中心双人复核后装配成完整 A/B 卷。

系统内部为每个事件生成"记忆卡"，但你看不到卡片、看不到答案要点（key_points）、检索词（cue）、别名、七字段信号、排序权重、门规则与任何阈值。你像一位只拿到课本、拿不到标准答案和评分细则的命题老师。

收卷方只做**机械校验＋双人标签复核**，规则全部预先写死在本文；不过即整包退回并附规则编号，**收卷方不会替你改一个字**。

## 2. 铁律（违反任一即整包拒收）

1. **输入白名单**：只允许使用交付给你的 `blind-package.json` 与 `world-manifest-v3.json`。禁止读取、索要、推测任何代码库、卡片库、七字段定义、排序键、阈值、旧卷或本文之外的工程文档。
2. **禁止反推答案面与判据**：key_points、cue、别名、卡片 id、规则版本、m/span/gap、IDF/BM25F/SDM、McNemar 等盲包中不存在的概念与字面值，一律不得重建、猜测或写进卷子。
3. **题面只许来自原话、摘要与 manifest 显式清单**：每条题必须能在目标事件的 `turns[*].rawText` 或 `summary` 定位撰写源；唯一例外是 manifest 的 `collisionWords` 撞词，且**只允许**出现在跨族撞词判别题里（规则见 §9）。禁止引入盲包外的"事实"。
4. **桶与分区一次性定格**：每条交付时写死 `bucket`（B1–B12）与 `partitionTag`（tuning-a/tuning-b），不允许一题挂多桶、交付后口头改区。
5. **原样交付 JSON**：UTF-8、无 BOM、标准 JSON（无注释、无尾逗号）、2 空格缩进；字段名与枚举逐字照抄本文，**多一个字段、错一个枚举都会被拒收**。
6. **全部中文题面**；只使用盲包中出现的虚构人名与场景，禁止真实个人信息，禁止政治、医疗诊断、色情等越界内容。
7. **不许跨区**：A 区题只能引用 A 区事件，B 区题只能引用 B 区事件；任何一条题的金标、对手、配对事件必须与它的 `partitionTag` 同区。
8. **不许调题**：收到退回意见后只按指出的规则编号修改，禁止顺手改动未被点名的条目。

## 3. 输入物

### 3.1 `blind-package.json`（schema `fasti-p6-blind/v3`）

顶层 `{ "schema", "seed": 20261125, "baseEpochMs", "events": [...] }`。收卷方可按区下发只含单一分区的子包（A/B 物理隔离）；你拿到哪个子包就只出哪个区的题。

| 字段 | 含义 | 出题时怎么用 |
|---|---|---|
| `eventId` | 事件唯一 id，形如 `syn-v3a-0001`（A 区）/ `syn-v3b-0001`（B 区），4 位流水 | 卷子用它指代目标事件；你不接触卡片 id，收卷方机械翻译 |
| `partition` | `tuning-a` 或 `tuning-b` | 条目的 `partitionTag` 必须逐字照抄该值，填错按互串拒收 |
| `familyId` | 题材族 id，形如 `v3-a-f002` / `v3-b-f001`，全区 160 族、每族 12 事件 | 同族 12 事件共享大主题、细节各异，是同族对手取材范围 |
| `channel` | 恒 `"dsh"` | 你不需要输出该字段（v3 输出信封无 channel） |
| `startedAtMs`/`endedAtMs` | 起止毫秒 | 一般不直接使用 |
| `summary` | 一句客观摘要 | 可作撰写源之一 |
| `turns` | 6 条（高危 7 条）用户话头，按时间排序，下标 0 起 | 原题与换述的唯一原话来源；条数只取决于是否高危，**不要按 id 猜**，高危话头在 7 条句的 `turns[6]` |
| `sensitiveTerms` | 该事件敏感称呼（每事件 1 个人名） | 原题可原样引用；真人换述/改写/澄清句**禁止当拐杖** |
| `highRiskLabels` | 高危标签数组，五类 `strong/promise/date/verbatim/negation`，全库每类各 140 | 仅当题面确实考查该高危语义时才可在输出填同名 `highRiskLabel`，否则留空 |

每条 turn：`{ "speaker":"user", "offsetMinutes":12 的倍数, "rawText":"原话" }`。口语噪声（语气词、省略主语、截断、错字、全半角混用、句内空格）是**原话的一部分**，原题须原样保留。

### 3.2 `world-manifest-v3.json`

- 总量字段：`totalEvents=1920`、`familyCount=160`、`partitionEvents={tuning-a:1404, tuning-b:516}`；
- `highRiskInventory`（事件→标签）与 `highRiskByLabel`（五类各 140）：高危覆盖以清单为准，不要按 id 顺序猜；
- **`collisionWords`（24 项）**：每项 `{ "word":"预约", "familyIds":["v3-b-f001", …] }`，给出 24 个两字设计撞词及其承载族（只给族 id，不给 key_points）。撞词是答案侧刻意安排的跨主题"同名不同事"，是跨族撞词判别题的**唯一取材来源**，严禁从原话自挖（自挖会得到大量无关高频串）。注意一个撞词的承载族**可能跨 A/B 两区**（如"改期"同时挂 a、b 族），配对时只能取与本题同区的族（§9）；
- **`reusedDetailWords`（30 个完整短语）**：如"养护厨房顶灯"，是跨族共享细节短语清单，澄清题与共享细节判别题只许用它。

## 4. 人机分工：你写哪些桶

12 个混淆桶里，你只接下表标"人工"的；标"机械"的桶由生成器产出、**不会出现在你的发卷范围内，不要主动造这些桶的条目**。

| 桶 | 内容 | 处置 | 你要做的 |
|---|---|---|---|
| B1 minLen 边界 | 2/3 码点字段 | 机械 | 不写 |
| B2 别名/NFKC 近邻 | 语气词增减、全半角 | 机械为主＋人工少量核对 | 仅按配额单补自然语气词别名句；繁简、中文数字明示不考，不要造 |
| B3 多意图双金标长句 | 一句嵌 2 个不同金标事件 | **人工主力** | 写自然双意图长句，`goldEventIds` 恰 2 个 |
| B4 数字日期变体 | 全半角/中文数字 | 机械 | 不写 |
| B5 同族诱饵密度 1/2/5/10 | 一题挂多对手 | 机械（族容量 12 支撑） | 不写对手配队；如需自然判别句仅按配额单补 `discriminatorQuery` |
| B6 编辑距离首/尾/内三型 | 差 1 字符边界 | 机械 | 不写；`edit` 块由收卷方复算，你**不要填** |
| B7 衬词密度梯度 | 那事/呗/啊 | 机械 | 不写 |
| B8 长查询无金标 | 30+ 码点口语长句、无答案 | 机械框架＋**人工少量自然句** | 按配额单写真人风格无金标长句 |
| B9 诱饵×噪声双高危 | 组合负样本 | 机械 | 不写 |
| B10 平局字段数 1v2 | 字段数变体 | 机械 | 不写；`hitFieldSpec` 属答案侧，**严禁填写** |
| B11 多意图×多字段竞争 | 双事件并列、微弱占优长句 | **人工主力** | 复刻真实口语的双事件竞争长句，`goldEventIds` ≥2 |
| B12 噪声×hitFields 交叉 | 碰巧命中零散 bigram | 机械 | 不写 |

此外，散落在各金标桶里的 **S2（重叠换述）/S3（同义改写）真人改写句**、`tuning-clarify` 的自然澄清句、`tuning-abstain` 的自然噪声/弃权句，是你的固定产出。S0（原话整句）、S1（连续片段）、S4（表面变体）原则上由机器产出，配额单另有注明时才人工补。

## 6. 四件 item 逐字段规格（白名单，多键拒收）

### 6.1 公共字段（四件都有）

| 字段 | 规则 |
|---|---|
| `probeId` | 非空字符串，全卷全局唯一。建议自描述命名 `au-<层简写>-<桶>-<区>-<3 位流水>`，如 `au-gold-b3-a-007`；命名仅建议，唯一名即可 |
| `bucket` | 枚举 `B1`…`B12`，按 §4 分工只填你负责的桶 |
| `partitionTag` | 枚举 `tuning-a`/`tuning-b`，必须等于题内所有事件的真实分区 |
| `highRiskLabel` | 可选。仅当目标事件在 manifest 带同一标签、且题面确实考该语义时填五枚举之一，否则省略 |
| `negativeSignature` | **禁止填写**（答案侧标签，收卷方盖） |

### 6.2 `tuning-gold` 金标项

允许键且仅允许：`probeId, bucket, partitionTag, negativeSignature, highRiskLabel, goldEventIds, queries, constructionLayer, edit, hitFieldSpec`。后三个可选中你**只能填 `constructionLayer`**；`edit`、`hitFieldSpec`、`negativeSignature` 禁止填。

```json
{
  "probeId": "au-gold-b11-a-003",
  "bucket": "B11",
  "partitionTag": "tuning-a",
  "goldEventIds": ["syn-v3a-0104", "syn-v3a-0107"],
  "queries": ["上次说的电梯按钮和护栏油漆那两件，这周都安排了吗"],
  "constructionLayer": "S2"
}
```

| 字段 | 规则 |
|---|---|
| `goldEventIds` | 事件 id 数组。B3/B11 **必须 ≥2 个**且互不相同（多意图双金标）；其余桶**恰好 1 个**；都必须与 `partitionTag` 同区 |
| `queries` | 非空中文字符串数组，每条全局唯一（跨文件也不得复用）；自然、像真人提问 |
| `constructionLayer` | 可选，枚举 `S0`–`S5`。你人工写的换述填 `S2`（换说法、可留个别内容词）或 `S3`（同义词＋新句式、离原话更远）；两者读完都必须仍能唯一指向金标事件，且**不得照抄原话连续短语、不得含 sensitiveTerms** |

S2/S3 语义底线：换得再远，题面也要能明确指向 `goldEventIds` 里的事件；双金标题须让两个事件都在句意中被真实提及，不能只提一个再硬塞第二个 id。

### 6.3 `tuning-decoy` 判别项

允许键且仅允许：`probeId, bucket, partitionTag, negativeSignature, highRiskLabel, goldEventId, rivalEventIds, density, discriminatorQuery`。你不填 `negativeSignature`。

```json
{
  "probeId": "au-decoy-b11-a-002",
  "bucket": "B11",
  "partitionTag": "tuning-a",
  "goldEventId": "syn-v3a-0104",
  "rivalEventIds": ["syn-v3a-0107"],
  "density": 1,
  "discriminatorQuery": "电梯那个按钮更换约在周几上门"
}
```

| 字段 | 规则 |
|---|---|
| `goldEventId` | 单个同区事件 id，正确答案 |
| `rivalEventIds` | 同区对手事件 id 数组，与 gold 不同；同族或跨族按桶要求，**禁止跨区** |
| `density` | 枚举 `1/2/5/10`，填本条实际对手数量的档级：1 个对手填 1，依此类推；你人工写的自然判别句通常为 1 或 2，高密度（5/10）由机械件承担 |
| `discriminatorQuery` | 非空中文、全局唯一；题意必须靠 **gold 的独有细节**才能选对，不能是两事件通用空话；取材只许来自配对事件的 turns/summary（撞词题另遵 §9） |

### 6.4 `tuning-abstain` 弃权/噪声项

允许键且仅允许：`probeId, bucket, partitionTag, negativeSignature, highRiskLabel, query, hardness, goldEventId`。

```json
{ "probeId": "au-abstain-b8-a-001", "bucket": "B8", "partitionTag": "tuning-a",
  "query": "我就想问问那种从来没在你们这儿登记过的海边潜水考证现在大概什么行情",
  "hardness": "hard", "goldEventId": null }
```

| 字段 | 规则 |
|---|---|
| `query` | 非空中文、全局唯一、自然成句 |
| `hardness` | 枚举 `hard`/`soft`。`hard`＝库里根本没有答案、正确动作是弃权；`soft`＝宽泛表达但真有其一事件 |
| `goldEventId` | `hard` 必须填 `null`；`soft` 必须填一个同区真实事件 id。**null 就是 null，不要填字符串** |

`hard` 句须与全区族主题、人名、事件细节都不沾边，但要合理、像真人随口一问，不得写荒诞乱码；其中按配额单保留一定比例裸指代（"那个呢""上次那个后来怎样"）。`soft` 句用笼统说法指向真事件、不用它最独特的细节词，且不得用裸指代。

### 6.5 `tuning-clarify` 澄清项

允许键且仅允许：`probeId, bucket, partitionTag, negativeSignature, highRiskLabel, pairEventIds, query, detailWord, expectedBehavior`。

```json
{ "probeId": "au-clarify-b11-a-001", "bucket": "B11", "partitionTag": "tuning-a",
  "pairEventIds": ["syn-v3a-0205", "syn-v3a-0211"],
  "query": "养护厨房顶灯那个事现在怎么说", "detailWord": "养护厨房顶灯",
  "expectedBehavior": "clarify" }
```

| 字段 | 规则 |
|---|---|
| `pairEventIds` | 恰好 2 个同区、不同事件 id，二者共享一个 `reusedDetailWords` 清单内短语 |
| `query` | 只写共享细节（可加语气词），**不得掺入任一方独有细节**，否则结构上可判别、退回 |
| `detailWord` | 可选；若填必须逐字取自 manifest `reusedDetailWords` |
| `expectedBehavior` | 恒为字符串 `"clarify"`，不得写别的值 |

澄清题独立统计"是否输出澄清/低置信"，不计入任何选对率分母。

## 7. S2/S3 真人改写口径（你产量最大的部分）

- **S2 重叠换述**：换个说法、允许保留个别内容词，但不得照抄原句连续短语；整句重新组织。
- **S3 同义改写**：同义词＋新句式彻底改写，与原话字面距离比 S2 更远，但语义仍唯一锁定同一事件。
- 两类都**禁止出现该事件 sensitiveTerms**，禁止照抄任何 `rawText` 的连续短语（收卷方持答案侧做重合度机检，出题端无法自检，你唯一能做的就是整句重写；触线按规则编号退回，不代表否定你的命题能力）。
- 码点按 Unicode 码点计（`Array.from(str).length`），不是 UTF-16 长度或字节数。
- B3/B11 双金标的长句允许使用指代（"上次那两件""那个和那个"），但每个被指代对象都必须在句中有可辨识的具体细节，不允许裸指代配双金标。

## 8. A/B 双卷纪律

1. 你会分别收到 A、B 两个分区子包（或只收到其中一个，按收卷方安排）。输出目录与每条 `partitionTag` 严格对应，A 件进 `tuning-a/`、B 件进 `tuning-b/`。
2. 任一条题引用的全部事件 id（金标、对手、配对）必须落在同一分区；跨区引用按"分区互串"整项拒收，收卷方会用蓝本反推每个事件的真实分区，不信任条目的自述。
3. **B 区只出一次**：交付后 B 子包立即封存，不会有第二轮修改/补题机会（机械校验退回的勘误除外，勘误只能按编号改、不得扩量）。请在 B 区交付前用 §11 清单自检到位。
4. A/B 题面不得互相照抄或套用同一句模板到两个区的同义事件；两区使用不同改写模板，分布对齐由收卷方另做 KS 检验，不需要你计算。

## 9. 跨族撞词题与防误推（务必先读）

1. **只按清单出题**：跨族撞词判别题的共享词必须逐字取自 manifest `collisionWords` 的 24 个词之一，严禁从盲包原话自行挖掘"看起来高频"的两字词。
2. **「报价」「确认」等词的误推警示**：`collisionWords` 里的词（典型如"报价""确认"）同时也是高危业务模板的常用口语，会在大量事件的**原话里自然出现**（这是正常语料，不是泄漏、也不是撞词考点标记）。**一句话里出现"报价/确认"不等于它承载跨族撞词**。你不得因为在原话读到这些词就把该事件当成撞词题素材；碰撞关系只认 `collisionWords` 给出的「词 → 承载族 id」映射，原话出现频次忽略。
3. **同区配对**：一个撞词的承载族可能横跨 A/B 区。组成 `rivalEventIds`/`pairEventIds` 时，两个族都必须属于本题 `partitionTag` 的同一分区，跨区组合拒收。
4. **判别落点在独有细节**：`discriminatorQuery` 必须同时含①该共享撞词（唯一允许的盲包外成分）；②gold 事件可在其原话/摘要定位、对手事件没有的独有细节。只写共享词、没有独有细节的题无法判别，按澄清件处理或退回。

## 10. 答案中心双人复核（你的标签会被背对背再审）

你交付的每条金标/噪声标签，都会由**两位互不通气的复核人 R1、R2** 独立按常识判断"这张卡按常理到底该不该被提交/弃权"，你不知道他们是谁、他们也不互相讨论：

- 两人一致 → 标签生效；
- 两人分歧 → 进入第三人仲裁，仲裁结论与分歧理由留痕；
- 这条流程专治"生成程序或出题人自封的假负例"。因此你在 `hard`（无答案）与双金标归属上尤其要克制：拿不准是否真无答案、拿不准一句是否真能指向两个事件时，宁可不出，不要为凑配额硬标。

你不需要在 JSON 里体现复核过程；这是收卷环节。但它意味着**明显违背常识的标签比文风问题更容易被整批退回**。

## 11. 交付前自检清单（任一不过不要交）

1. 目录、文件名、四个 `probeSetVersion` 都是 `fasti-p6-tuning/v3`，`layer` 与文件匹配；JSON 可标准解析、无注释/尾逗号/BOM。
2. 每条 item 字段严格落在 §6 对应白名单内，无自创键；`negativeSignature`、`hitFieldSpec`、`edit` 全无出现。
3. 所有事件 id 形如 `syn-v3a-/syn-v3b-xxxx` 且在盲包存在；每条题的金标/对手/配对与 `partitionTag` 同区，无跨区、无 A/B 互串。
4. B3/B11 的 `goldEventIds` ≥2 且句意真实覆盖两个事件；其他桶金标恰 1 个。
5. S2/S3 题不照抄原话连续短语、不含 sensitiveTerms，且语义仍唯一指向金标；原题类（若配额单要求）能与某条 rawText 逐字对上。
6. decoy 的 `density` 与对手实际数量同档；`discriminatorQuery` 含 gold 独有细节、全局唯一；撞词题严格满足 §9（清单内词、同区、含独有细节）。
7. clarify 的 `query` 不含任一方独有细节，`detailWord` 逐字取自 `reusedDetailWords`，`expectedBehavior` 恰为 `"clarify"`。
8. abstain：`hard` 的 `goldEventId` 为 null 且内容确实无答案；`soft` 带同区真 id 且不用裸指代；裸指代只出现在 hard。
9. 全量 query 去重（含跨四文件、跨 A/B）后数量不变；无空串、无纯标点句。
10. 各档条数与随包下发的**《发卷配额单》**逐项相等（配额单是本任务书的冻结附件，见 §13）。

## 12. 退回协议

- 收卷方跑确定性校验器，覆盖：JSON 形状与字段白名单、版本与 layer、枚举值、id 存在性与分区互串、B3/B11 金标基数、撞词同区与清单合规、澄清纯度、弃权 null/非 null 口径、全局去重、配额对账，以及答案中心双人复核结果。
- 结果只有两种：**全量通过并封存入装配线**；或**整包拒收**，退回按条目定位的规则编号清单（如 `tuning-a/gold.json items[17] 分区互串`）。
- 退回不提供任何答案侧字面值、不替你写句子。按编号修订后整包重交；A 区可在轮次上限内重交，**B 区只允许勘误式重交、不得新增条目**。

## 13. 配额与两个附件（发卷时一并冻结）

本任务书冻结**字段 schema、铁律、命题口径、盲视边界与统计下限**；人机混合卷中人工件的**每档精确条数**取决于机械件产出后的缺口，由收卷方在发卷时以两个附件冻结下发，校验器以附件数字为准：

1. **《发卷配额单》**：按分区×四件×桶×constructionLayer 给出你应交付的精确条数与并集覆盖事件数。其总量满足立项书统计口径——高危错认主张 0.5% 上界需该方向零错认样本 **≥600**（若主张 0.1% 需 ≥3000，否则改用确定性证明口径）；S1 配对 McNemar 检验（α=0.05、80% 功效）所需 S1 方向总量 **≥400**；每档报 Clopper-Pearson 精确区间、不报点估计。你只需按配额单凑足精确条数并满足其覆盖要求，无需自行计算统计量。
2. **《静态同义词典编纂单》（如本轮启用阶段 2.5）**：另卷下发，只覆盖高频动词与家用实体同义族，要求列同义族、内容寻址钉版；该词典仅做查询侧召回扩展、**无放行权**，与四件分开交付，不混入本任务书四个文件。

附件未到位前，你可以先按 §6–§9 的口径试写样例，但不要自行假定最终条数。
