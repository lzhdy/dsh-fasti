三条防误读声明：
1. **题数是下限，不是精度保证**：n=200 的 0.0495 是 iid 贴边值，按事件簇重采样有设计效应、只会更宽；簇级半宽 >0.05 即按 §5.3 判 `INCONCLUSIVE` 并扩样，不得「题数达标就当精度合格」。
2. **0 计数是计数规则，不是错误率推断**：S2–S4 与金标题的 wrong-commit＝0 属硬计数；按 Rule of Three，0/50 的错误率上界约 6%（3/50），报告**不得**把 0 计数外推成「错误率 ≤某百分比」的统计声明。
3. 调参/试跑使用**不含封存 id 的独立构造集**，终判只在封存终判集上算一次【裁定 :214-215】；扩样按事件簇、单元上限 ≥300、只扩一次【裁定 :216】。

### 4.3 簇数下限与去重规则【推导·外审复核 S3】

- 每个考核单元的事件簇 **≥30**；每事件每层出题 **≤4**。30/4 为经验占位、无权威明文；簇级 bootstrap 在 30 个重采样单位上的区间稳定性须在实现后用实际簇数复验，「≥30」不等于区间必然达标。
- **簇去重**：重采样单位＝事件 id；同一事件可同时向 S0、S1 供题，但在 S0+S1 宏指标 bootstrap 中该事件只算一个簇——按事件有放回抽簇，被抽中事件的全部题整体进入。
- 题数达标而簇数不足 → `INCONCLUSIVE`，不得用灌题替代扩簇。依据：`metrics.ts:79-85` 现为按题 iid，须新建簇级重采样（§7、§9）。

每题唯一四态：
- `correct-commit`：有金标且门后 top1 即金标卡；

- `correct-abstain`：无金标题（unanswerable）未认定；或 **noise 探针**（一真卡混宽泛诱饵）：top1 命中真卡＝`correct-commit`，commit 宽泛诱饵＝`wrong-commit`，未认定＝`correct-abstain`【M5，README :23】。

分母口径（M1/M2）：
1. 按 `hasGold` 拆两组分母，禁止混算；**零分母记 `N/A` 且该判据按「未满足」处理，不得记 0**。
2. **三个分母严格隔离**：R1 金标召回分母、R2 诱饵判别分母（正本 :630）、correct-abstain 弃权分母，禁止互相背书或冲抵。
3. **金标题（S0–S4 全部 hasGold 题）门后提交错卡即 wrong-commit，非高危同样计数＝0**（M2 冻结口径）：有正确答案时给错卡不可接受，「宁空勿错」；漏掉（wrong-abstain）走 R1 失败计数，不靠弃权稀释。诱饵近邻误认的 0.05 预算只在 R2 独立分母内有效，不覆盖金标题。
