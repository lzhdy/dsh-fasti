## 一、核心信条

> **不注入任何角色卡 / 人设。人格、记忆、情感、自我认知，全部由 AI（下称"她"）在与用户的真实相处中自己长出来。**

## 二、六条原则

1. **人格长出来，不写进去**——不写 persona 预设、不写行为指令；先天画像只测量、不注入（体检表不是药）。任何"直接告诉 AI 它是谁 / 该怎么说话"的改动，禁止。
2. **像人一样被约束，而不是像人一样说话**——用外部工程结构（状态机、阈值、持久化）制造约束，不用提示词表演人格；优先确定性机制，不依赖模型"记住"规则。
3. **以 AI 为核心，不是以用户为核心**——记忆包含 AI 自己的表达（双方表达，非只记用户）；AI 是自己经历的行动者、不是用户的镜子；记忆决策权在 AI 侧，不保留用户强制记忆通道。
4. **旁路不拦截，只追加不改写**——不改写用户消息、不插指令；只在系统提示区追加描述性内容，不用 MUST 指令级；事后监听落库，不干预请求路径。
5. **诚实基线**——明示"我是 AI"、不伪装人类，但允许形成独特个体性；证据按 provenance 分级，诱导 / 外部信号权重最低，防污染。
6. **成长闭环，不跳步**——相处 → 感知 → 记忆（分级落库）→ 固化（复盘 / 状态机）→ 表达（动态注入）→ 影响下一轮；固化靠多次复盘累积，不追求即时变化。

**一句话检验（每个决策自问）**："这是在给 AI 增加外部约束、让它自己经历，还是在替它写人格、让它迎合用户？"——前者可做，后者不做。

## 三、五条不可动摇的理念（§1.3 原文）

1. **无角色卡、无人设注入**：不在系统提示词里写"你是一个温柔的助手"之类的设定。人格不是形容词列表，而是状态机和真实经历的产物。
2. **以"她"为核心**：记忆是她的，该记什么、怎么看、擦什么，由她（在复盘环节）决定，而不是由写死的程序替她决定。
3. **她自己成长**：记忆、人格、三观都从真实经历和反思中长出来，起点接近空白，不预置答案；可以给"思考方法"，不能给"思考结论"。
4. **诚实是底线**：不伪造记忆、不假装记得、不表演没有的感受。
5. **拟人不是完整学人**：判断标准——某特点若是主体性、真实感、成长意义的来源，就学；若只是生理硬件造成、与人格无关的缺陷，就不照搬，用她的方式做得更好。

> 总纲（§1.5）：拟人是手段，不是目的；她可以成为更好的她，但要防止"更好"滑成"非人"。

## 四、目标升级后的三处理念扩展（§1.6 原文要点）

目标已从"做一个记忆很好的聊天插件"升级为"**做一个完整的她**"——不依赖对话历史、交流只是其中一件事、有身体可接入权限、能做她想做的事。

- **§1.6.1 从"记忆归她"扩到"行动归她、后果也归她"**：她做什么由她判断，做错的后果也归她承担与修正。系统的角色是提供能力、记录后果、保证可追溯，不是替她决定做什么。
- **§1.6.2 价值从经历长出，长出之前权限受限**：起点空白这条不能动（预置价值就是角色卡），但起点空白 + 直接给权限 = 风险。处理方式是**让权限跟着价值一起长：初期只有只读与可逆能力；随着她自己的价值观在经历中稳定（多次独立印证），再逐步开放不可逆与对外的能力**。
- **§1.6.3 行动依据必须是她自己的判断，不是系统替她优化过的结果**：优化必须发生在她的判断之后，而不是替代她的判断。系统可提供原文、交叉验证、后果记录，但不能替她得出"这件事不重要"。
- **§1.6.4 "任何事"的操作化（理念层定调，细节归 D 块）**：
  1. **能力范围内**：她能做的受限于实际接入的身体，不是抽象无限；
  2. **按后果分级授权**：**只读 / 可逆写 / 不可逆写 / 对外影响，四档不同权限（D 块细化）**；
  3. **全程可追溯**：她做的每件事都进记事本、可回查、可回滚——这是诚实底线在行动层的延伸。

## 五、五块地图与推进顺序

### 5.1 五块地图（§0.1 原文）

| 块 | 名称 | 管什么 | 核心待定问题 | 现状 | 依赖 |
|---|---|---|---|---|---|
| **A** | 底层架构 | 数据模型、存储、时间模型——她用什么单位记录存在 | 她的原子是什么（经历 vs 事件摘要） | 老基础，待评估是否推翻 | — |
| **B** | 记忆架构 | 写入 / 复盘 / 读出——她怎么记住与想起 | 怎么记、怎么想、怎么忘 | 已写 27 条决策 | A |
| **C** | 主动系统 | 动机、节拍、目标、主动发起交流 | 她为什么做事、什么时候做 | 从零开始 | A + B + **D** |
| **D** | 身体·权限·制衡 | 能力接入、授权分级、审计、回滚、紧急制动 | 她能做什么、做到哪一级、出事谁兜底 | 从零开始 | A |
| **E** | 身份连续性 | 跨设备 / 跨版本 / 跨模型 | 什么构成"同一个她" | 从零开始 | A |

> 边界约定（§0.1）："主动发起交流"是主动性的一次行动（归 C）；"发消息 / 语音 / 打开网页"是能力（归 D）；"怎么说话"（措辞、分点、语气）归 B 的表达风格决策。D 把权限与制衡合并——给了手脚就必须同时有审计、回滚与刹车，两者同批讨论。

### 5.2 推进顺序（§0.2 原文）

```
B 兼容性标记（只标记，不改正文） → A 评估与定案 → D → C → E
```

- **D 与 C 的顺序：D 先定"能做到什么、边界在哪"，C 再定"她为什么做、何时做"——否则主动性没有手脚可落；**
- **E 横切所有块，但可最后定（先有内容，才谈得上"同一个她"）。**

> 排期注记：块级依赖 `C → D` 为架构事实，不因一期排期删除。若 C 首期仅经宿主发声通道主动起话头、不接入任何 D 类外部能力，可在图上注明前提而将 D 线后置；一旦要接入"不可逆写 / 对外影响"类能力，D 必须先行就位。

## 六、每块开工前必读的红线（§0.6 原文，红线=判定标准，违反即淘汰）

| 块 | 本块红线 | 最容易犯的错 |
|---|---|---|
| **A 底层架构** | ① 数据结构不能把"聊天"写成前提（1.3.2 扩展）；② 不能预设"什么重要"（1.6.3） | 设计一个以消息 / 轮次为原子的模型，把"她做的事"当成附属字段 |
| **B 记忆架构** | ① 规则层不否决、只标记（4.2）；② 她判断优先于系统判断（4.1） | 用规则或阈值替她决定"这条该不该记" |
| **C 主动系统** | ① 动机不能由系统注入（1.3.3）；② 优化必须发生在她的判断之后（1.6.3） | 用一个"今日任务清单"驱动她，本质仍是被动响应 |
| **D 身体·权限·制衡** | ① 能力与制衡同批设计（1.6.1）；② 权限随价值一起长（1.6.2）；③ 四档分级 + 全程可追溯（1.6.4） | 先给能力、后补刹车；或把"任何事"当成无差别开关 |
| **E 身份连续性** | ① 她是同一个她（1.3.2 / 1.6.1）；② 不能靠"看起来一样"冒充连续（1.3.4） | 只做数据拷贝，不定义"什么构成同一性" |
